# mirrormerelabs.org

Source for the Mirrormere Labs website, built with [Quarto](https://quarto.org) and published with GitHub Pages.

## Editing

| To change | Edit |
|---|---|
| Home page | `index.qmd` |
| Projects and evaluations | `work/index.qmd` |
| A project page | `work/mozambique-poverty.qmd`, `work/cabo-delgado.qmd` |
| Services, how I work, tools | `services.qmd` |
| Publications | `publications.qmd` |
| About, Contact | `about.qmd`, `contact.qmd` |
| CV download | replace `files/Peter-Hargreaves-CV.pdf` |
| Email address | `_variables.yml` |
| Menu, footer, site description | `_quarto.yml` |
| Colours and fonts | `styles.scss` |

To add a project page, copy `work/cabo-delgado.qmd`, rename it, edit it, and add an entry for it in `work/index.qmd`.

Preview locally with `quarto preview`. Pushing to `main` publishes the site automatically (about a minute).

## First-time setup

1. Create a public repository called `mirrormerelabs.github.io` under the `mirrormerelabs` account and push these files to `main`.
2. In the repository, go to **Settings > Pages** and set **Source** to **GitHub Actions**. The workflow in `.github/workflows/publish.yml` then builds and publishes the site. Check it under the **Actions** tab.
3. Still in **Settings > Pages**, enter `www.mirrormerelabs.org` as the **Custom domain**.
4. At your domain registrar (Squarespace Domains, if the domain is registered there), set these DNS records, removing any old Squarespace ones for the same names:
   - `www` CNAME `mirrormerelabs.github.io`
   - `@` A records: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
5. Once the domain check passes in **Settings > Pages** (can take up to a day), tick **Enforce HTTPS**.
6. Optional but recommended: verify the domain under your GitHub account's **Settings > Pages** so nobody else can claim it.
7. Cancel the Squarespace website plan only after the new site is live at www.mirrormerelabs.org. Keep the domain registration.

Because this is the account's main Pages site, your other Pages projects (the project map, the Mozambique map) will also appear under the custom domain, for example www.mirrormerelabs.org/map/. Their old github.io links keep working.

## Home page artwork

`images/fells.svg` is generated by `tools/make_fells.py`, adapted from the GitHub banner script. To regenerate it:

```
python3 tools/make_fells.py images/fells.svg dark 900 600 430 0 1.9 11
```
