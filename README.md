# mirrormerelabs.org

Source for the Mirrormere Labs website, built with [Quarto](https://quarto.org) and published with GitHub Pages.

## Home page artwork

`images/fells.svg` is generated by `tools/make_fells.py`, adapted from the GitHub banner script. To regenerate it:

```
python3 tools/make_fells.py images/fells.svg dark 900 600 430 0 1.9 11
```
